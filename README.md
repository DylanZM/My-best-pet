# My Best Pet - Desktop Litten

A desktop pet created using **Godot 4.7**. Litten lives in a transparent, borderless window that stays on top of everything else. It can follow your cursor, wander around the screen, and react when you interact with it.

An unofficial fan project. Not affiliated with Nintendo, Creatures, or GAME FREAK.

## Features

- Transparent, borderless window that always stays on top.
- Litten follows the mouse cursor by default.
- Automatic wandering mode when not following the cursor.
- "Stay Still" mode: Litten stops and looks toward the cursor.
- Direction-based animations: walking, idle, sleeping, waking up, posing, and crying.
- Speech bubbles with random phrases.
- Heart particle effects.
- Drag-and-drop functionality with momentum; Litten bounces off the edges of the screen.
- Resizable using the mouse wheel; grows in size when the cursor hovers over it.
- Context menu with various actions.
- Saves position, scale, and preferences between sessions.
